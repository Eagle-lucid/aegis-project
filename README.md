# Aegis — The Throne Command System

> Not a dashboard. A throne.

Aegis transforms passive data dashboards into active, sovereign command centers. It combines a cinematic narrative with AI-powered intelligence to turn leaders into commanders.

**This monorepo contains:**

- `apps/landing-page`: The cinematic, narrative-driven marketing site.
- `apps/throne-app`: The functional MVP of the Aegis command interface.
- `packages/ui`: The TalonUI design system shared across all applications.

## 🛠 Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS + Framer Motion
- **3D:** React Three Fiber
- **Backend:** Supabase (Database, Auth, Realtime)
- **Monorepo:** Turborepo

## The Vision

Aegis is built on the thesis that current dashboards create passive observers. This project is an argument for a new paradigm: **Sovereign Computing**, where interfaces are designed to empower, protect, and inspire decisive action.
